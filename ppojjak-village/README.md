# 뽀짝 친구 마을

버전: v2.2 (리듬 콤보 · 가구 회전 · 한글 놀이 단계 길 + 모음 놀이/카드 짝 맞추기/낱말 조립/낱말 도감 · 부모 목소리 아닌 TTS 음성 81개)

한글을 몰라도 바로 즐기는 아이용 게임입니다. 설치 없이 `index.html`을 더블클릭하면 브라우저에서 실행돼요. (인터넷 불필요)

## 놀이
- 🍉 친구 합치기: 같은 친구끼리 닿으면 한 단계 큰 친구로 변신 (수박게임). 새 친구를 만나면 도감에 등록, 합칠 때마다 ⭐ 획득
- 🎵 리듬 놀이: 5개 칸에 내려오는 친구를 맞는 칸에 탭 (낮은 음은 왼쪽, 높은 음은 오른쪽). 곡 8개, 곡마다 별 1~3개 기록 (키보드 1~5 또는 A S D F G)
- 👗 옷 입히기: 모자·안경·옷·목 장식·몸 색깔, 🎲 랜덤, 🧼 초기화
- 🏠 집 꾸미기: ⭐로 가구를 사서 끌어다 놓기, 🗑️로 치우기, 벽지·바닥 색 바꾸기
- 🥚 알 뽑기: ⭐15로 알을 3번 톡톡 → 새 친구 (이미 있는 친구면 ⭐5 돌려받음)
- 📖 친구 도감: 12마리 모으기, 탭하면 그 친구가 내 대표 친구로

## 참고
- 진행 상황은 브라우저(localStorage)에 자동 저장됩니다. 같은 브라우저로 열어야 이어서 할 수 있어요.
- 친구 그림은 모두 코드로 그린 오리지널 캐릭터라 별도 이미지 파일이 없습니다.
- 소리는 첫 터치 후부터 나요. 홈 화면 왼쪽 위 🔊로 끌 수 있어요.
